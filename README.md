# 秋のひみつ研究所

小学2年 国語「あきが いっぱい」公開授業で使うWebアプリです。
対象端末：児童用iPad（Safari）

## これは何か

単元のほとんどはロイロノートで行い、**本時の「使う情報を選び直す」場面だけ**をこのアプリで支えます。

ロイロのテストカードは1問ずつ独立しているため、作り直す前と後を並べて比べる画面がありません。
「さいしょ」と「いま」を、使った情報・友だちの反応ごと並べることだけが、このアプリの役割です。

## 使い方

`index.html` を開くだけです。ファイル1つで完結しており、サーバーもインストールも要りません。
記録はその端末の中だけに保存され、外部には何も送信しません。

### 画面

| 画面 | いつ | すること |
|---|---|---|
| じゅんび | 前の時間に5分 | ロイロの記録をうつす（ひみつ3〜5枚／さいしょのクイズ／反応の人数） |
| ① ふりかえる | 本時 | さいしょのクイズへの反応を見る |
| ② えらび直す | 本時 | ピラミッドチャートを指で並べかえ、使うひみつを決める |
| ③ くらべる | 本時 | さいしょ→いま を並べ、変えた（変えなかった）わけを書く |

友だちの反応は、ロイロの集計を見て人数を＋−ボタンで入れます。
「かえない」判断も選べます。どちらを選んでも、わけを書く欄に進みます。

### 成果物

③の画面をスクリーンショットして、ロイロの提出箱に出します。
印刷／PDF保存ボタンもあります（③だけが印刷されます）。

## 設計方針

- 問題文も選択肢も自動生成しません。児童の言葉には手を入れません
- 「かえる」を正解にしません。かえない判断も同じ重さで扱います
- 個人情報は扱いません。入力するのは出席番号だけです

## 動作確認

76項目の自動テストを通しています（指ドラッグ、保存と復元、壊れたデータからの復帰、
保存できない端末での継続動作を含む）。
